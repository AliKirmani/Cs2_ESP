## 🌟 Overview

**Defiant-Eagle CS2 Tactical ESP Hub** is an elite, standalone 2D overlay and control panel engineered specifically for Counter-Strike 2. Designed with modern **Ocean RGB Breathing Wave** aesthetic borders, instant dynamic HSL gradient flows, and taskbar stealth window management, it offers ultra-fast real-time player telemetry rendering.

Developed and maintained exclusively by the **Defiant-Eagle Gaming Community**.

---

> [!IMPORTANT]
> **100% SAFE & STANDALONE EXECUTION**
> This tool features a self-contained multi-threaded internal telemetry rendering engine. It operates completely independently without requiring external command line consoles, external Python installations, or background tasks on your system taskbar.

---

## ✨ Key Features

| Feature | Description |
| :--- | :--- |
| 🌊 **Ocean Wave RGB GUI** | Dynamic 30 FPS continuous multi-stop HSL breathing gradient borders on both inner cards and main window boundaries. |
| 🎯 **Enemy vs Teammate ESP Toggles** | Independent UI toggles for `Enemy Team ESP` and `My Team ESP`. Turn enemy rendering ON while keeping team rendering OFF. |
| 🎨 **Fixed Enemy Color Mapping** | Dedicated color palette selection for enemies (Red, Crimson, Orange, Pink, Gold). Enemy color remains locked regardless of whether the enemy is playing CT or T! |
| 📏 **Dynamic Box Thickness** | Real-time slider adjustment for 2D bounding box outline thickness (1px to 5px). |
| ➕ **Sub-Feature Toggles** | Instant real-time toggles for **Health Bar**, **Player Name**, and **Active Weapon Label**. |
| 👻 **Taskbar Stealth Mode** | Extended Win32 `WS_EX_TOOLWINDOW` integration ensures zero extra Pygame or CMD console windows pollute your Windows Taskbar or Alt+Tab menu. |
| 🖥️ **High-DPI Alignment** | Full Windows Per-Monitor DPI Awareness (`SetProcessDpiAwareness`) ensuring pixel-perfect 2D screen coordinate projection across 1080p, 2K, and 4K displays. |
| 💬 **Community Integration** | One-click instant access button to the official **Defiant-Eagle Discord Support Server**. |

## 🚀 Quick Start Guide

### Prerequisites
- Windows 10 / Windows 11 (64-bit)
- Counter-Strike 2 (`cs2.exe`) running in **Windowed** or **Borderless Fullscreen** mode.

### Installation & Launch
1. Download or extract the contents of the release package.
2. Double-click `TestMaster.exe` (or run `run_app.bat`).
3. Launch Counter-Strike 2. The status badge will automatically turn **🟢 CS2 ACTIVE**.
4. Adjust your preferred Enemy Color, Box Thickness, and Sub-Toggles directly from the sleek Ocean RGB Control Panel!
